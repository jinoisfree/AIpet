# AIpet

**AIpet.v1**은 Codex와 Claude Code의 작업 상태를 알려 주는 독립형 macOS 데스크톱 펫입니다. AI가 작업하는 동안 태식이가 화면에 머물며 작업 중·확인 필요·응답 종료 등의 상태를 표시합니다.

`v1`은 첫 번째 주요 버전을 뜻하며 현재 앱 버전은 **1.0.3**입니다. Swift, AppKit, SwiftUI로 구현했습니다. 실행할 때 Python, Node.js, API 키가 필요하지 않습니다.

## 주요 기능

- **여러 AI 작업 표시**: Codex와 Claude Code가 동시에 일하면 말풍선에 두 서비스 이름을 함께 표시합니다. 서비스별 작업 목록과 작업 고정을 지원합니다.
- **이름과 크기 설정**: 펫 이름을 1~20자로 변경하면 안내·말풍선·미리보기·접근성 설명에 반영됩니다. 크기는 25~200%로 조절하며 말풍선과 글자 크기는 유지됩니다.
- **자연스러운 움직임**: 좌우 이동, 대기, 작업, 승인 대기, 응답 종료 등의 애니메이션을 표시합니다. 작은 자세에 맞춰 표시 비율을 보정해 고개를 돌릴 때 크기가 급격히 바뀌는 현상을 줄였습니다.
- **커서 따라보기**: 캐릭터에 커서를 올리면 한 번 점프한 뒤 16방향으로 따라봅니다. 진입 후 10초 동안 같은 화면 안에서 추적하며 추적 중 재진입은 시간을 갱신합니다.
- **화면 가장자리 대응**: 말풍선이 화면 안쪽으로 부드럽게 이동하고 위쪽 공간이 부족하면 아래로 배치됩니다.
- **작업 상태 점멸**: 작업 중에는 초록색 점이 1.6초 주기로 부드럽게 점멸합니다. 일시 중지·숨김·‘동작 줄이기’에서는 점멸하지 않습니다.
- **AI가 사용하는 창 바라보기**: 화면 도구 기록에서 창을 식별할 수 있으면 그 창을 바라봅니다. 여러 AI가 화면을 사용하면 **AI 작업 자체를 먼저 시작한 순서**로 대상을 선택합니다.
- **로컬 처리**: 로컬 기록과 선택적 공식 훅으로 상태를 읽습니다. 자체 LLM 호출이나 대화 내용의 외부 전송은 없습니다.

## 지원 환경

| 항목 | 지원 범위 |
|---|---|
| CPU | Apple Silicon (`arm64`) |
| 운영체제 | macOS 13 이상을 빌드 대상으로 지정 |
| AI 연결 | 같은 Mac의 Codex, Claude Code 로컬 기록 및 공식 훅 |
| 실행 의존성 | 별도 런타임·API 키 불필요 |
| 빌드 의존성 | Xcode 명령행 도구, Python 3, Pillow 11.3.0 |

Intel Mac용 바이너리는 제공하지 않습니다. 이전 macOS 버전별 실행은 별도 검증이 필요합니다. macOS 26 이상에서는 네이티브 유리 효과를, 이전 버전에서는 배경 블러를 사용합니다.

일반 ChatGPT·Claude 웹/앱 채팅과 원격 호스트의 작업은 현재 지원하지 않습니다. 다른 AI는 공통 작업 모델에 맞는 연결 모듈을 추가하는 방식으로 확장할 수 있습니다.

## 다운로드와 실행

[Releases](https://github.com/jinoisfree/AIpet/releases)에서 Apple Silicon용 ZIP을 내려받아 압축을 풀면 `AIpet.v1.app`이 나옵니다. 응용 프로그램 폴더에 복사한 뒤 실행할 수 있습니다.

현재 빌드는 **ad-hoc 서명**이며 Developer ID 서명·Apple 공증을 받지 않았습니다. 다운로드한 앱은 macOS 보안 정책에 따라 실행이 제한될 수 있습니다.

펫을 클릭하면 작업 목록, 드래그하면 위치 이동, 오른쪽 클릭이나 메뉴 막대의 발바닥을 누르면 옵션·미리보기·숨김·일시 중지·종료 메뉴가 열립니다. 이름·크기·위치는 재실행 후에도 유지됩니다.

## 소스에서 빌드

Xcode 명령행 도구와 Python 3가 준비된 Mac에서 실행합니다.

```bash
git clone https://github.com/jinoisfree/AIpet.git "$HOME/Projects/AIpet"
cd "$HOME/Projects/AIpet"
python3 -m venv "$PWD/.venv"
source "$PWD/.venv/bin/activate"
python3 -m pip install -r "$PWD/requirements-build.txt"
bash "$PWD/scripts/test.sh"
bash "$PWD/scripts/build.sh"
python3 -m unittest discover -s "$PWD/Tests" -p 'test_*.py'
open "$PWD/dist/AIpet.v1.app"
```

새 설치본을 사용자 응용 프로그램 폴더에 복사하려면 다음 명령을 사용합니다. 기존 설치본이 있으면 교체하지 않고 중단합니다.

```bash
python3 "$PWD/scripts/install.py"
```

배포용 ZIP은 빌드 후 생성합니다. 기존 버전의 ZIP이 있으면 덮어쓰지 않습니다. 압축 해제 후 서명과 실행 권한도 확인합니다.

```bash
bash "$PWD/scripts/package.sh"
```

## AI 연결

기본적으로 `~/.codex/sessions`와 `~/.claude/projects`를 읽습니다. `CODEX_HOME`, `CLAUDE_CONFIG_DIR` 환경 변수를 지원합니다. 최근 24시간의 기록을 확인하며 변경분은 2초, 새 파일은 15초 간격으로 탐색합니다.

공식 훅을 연결하면 승인 대기 등 상태 정보가 보강됩니다. 설치 후 아래 명령으로 추가할 설정을 먼저 확인합니다.

```bash
python3 "$PWD/scripts/configure_hooks.py" --app "$HOME/Applications/AIpet.v1.app"
```

검토한 뒤 `--apply`를 추가하면 **없는 설정 파일만** 생성합니다. 기존 `~/.codex/hooks.json` 또는 `~/.claude/settings.json`이 있으면 자동 병합·덮어쓰기를 하지 않습니다. 기존 설정과 출력된 훅 항목을 검토해 병합해야 합니다. 사용자 지정 설정 디렉터리를 쓰는 경우 생성된 경로를 직접 확인하세요.

Codex 훅은 `/hooks`에서 사용자 신뢰 검토가 필요합니다. Claude Code도 `/hooks`에서 반영을 확인하세요. 훅은 승인·거부를 결정하지 않으며 stdout에 내용을 반환하지 않습니다. 현재 작업을 자동 재시작하지 않습니다.

## 상태 표시와 개인정보

- ‘응답 종료’는 응답이 끝났다는 의미이며 작업 성공 판정이 아닙니다. 5분 동안 새 상태 기록이 없으면 ‘상태 확인 필요’로 표시합니다.
- 서비스별 최근 파일 최대 200개, 작업 목록 최대 200개를 확인합니다. 큰 파일의 초기 읽기는 뒤쪽 2MiB로 제한합니다.
- 작업 시작 이벤트가 읽은 범위에 없으면 최초 관측 시각으로 정렬합니다. 이 경우 실제 시작 순서를 확정할 수 없습니다.
- 창 시선은 화면 도구 출력에서 관측된 앱·창 이름과 공개 macOS 창 좌표로 결정합니다. 창을 구분할 수 없으면 임의의 다른 창을 선택하지 않습니다. Claude 도구가 필요한 창 정보를 제공하지 않으면 시선 대상은 미확인입니다.
- Codex 내부 가상 커서 좌표는 직접 연결하지 않습니다. 일반 터미널·웹 검색·API 호출은 화면 점유로 취급하지 않습니다.
- 대화 본문·추론 내용·도구 출력·스크린샷을 복제해 보관하거나 외부로 전송하지 않습니다. 훅 이벤트에는 작업 식별자·상태·시각 등의 메타데이터가 저장됩니다.
- 진단 스냅샷에는 작업 식별자·프로젝트 폴더 이름·앱·창 이름이 포함될 수 있습니다. 공개 이슈에 첨부하기 전에 개인 정보를 확인하세요.

기존 설정과의 호환성을 위해 내부 번들 ID `com.jinoisfree.taesik`, 실행 파일 `Taesik`, 데이터 경로 `~/Library/Application Support/Taesik`은 유지합니다. 사용자에게 보이는 앱 이름은 `AIpet.v1`입니다.

## 프로젝트 구조와 검증

| 경로 | 역할 |
|---|---|
| `Sources/` | 앱, 작업 상태 해석, 펫 UI·애니메이션·시선 처리 |
| `Resources/Pet/` | 태식이 원본 manifest와 스프라이트, 원본 이용 조건 |
| `Tests/` | 합성 기록 기반 상태·훅·배치·애니메이션·스프라이트 검사 |
| `scripts/` | 테스트, 빌드, 패키징, 신규 설치, 훅 설정 미리보기 |
| `docs/검증.md` | 재현 명령과 검증 범위 |

로컬 기록 형식은 버전에 따라 바뀔 수 있으며 알 수 없는 기록을 성공으로 추정하지 않습니다. 빌드 산출물·개인 작업 기록·설치 백업·진단 결과는 Git에 포함하지 않습니다.

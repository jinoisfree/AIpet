# AIpet.v1 1.0.3 검증

2026-10-01에 공개용 소스를 새 폴더에서 테스트하고 Apple Silicon용 앱과 ZIP을 빌드했습니다. 개인 작업 기록과 설정 대신 합성 이벤트·임시 디렉터리를 사용하는 검증입니다.

## 재현

저장소 루트에서 빌드 의존성을 준비한 다음 순서대로 실행합니다. Python 훅 테스트는 빌드된 앱 실행 파일을 사용하므로 앱 빌드 후 실행해야 합니다.

```bash
bash "$PWD/scripts/test.sh"
bash "$PWD/scripts/build.sh"
python3 -m unittest discover -s "$PWD/Tests" -p 'test_*.py'
bash "$PWD/scripts/package.sh"
```

## 범위와 한계

- 이번 공개 준비에서는 설치된 앱이나 실제 AI 설정을 교체하지 않았습니다. GUI 동작을 새로 조작하는 검증은 수행하지 않았습니다.
- 동시에 실행한 두 AI의 실제 화면 조작 연결, Codex 훅의 사용자 신뢰 승인, macOS 버전별 실행 호환성은 이 테스트 결과만으로 보장하지 않습니다.
- 테스트에서 확인한 작업 우선순위와 창 선택은 합성 기록·창 메타데이터 기반입니다. 실제 도구 출력에 창 정보가 없으면 대상 창을 결정할 수 없습니다.
- 개인정보 검사는 공개 후보 파일과 ZIP에 한정합니다. 로컬 로그·설정·진단 스냅샷·설치 백업은 업로드 대상에서 제외했습니다.
- 릴리스 ZIP은 ad-hoc 서명이며 Developer ID 서명과 Apple 공증을 받지 않았습니다.

## 1.0.4 이름 변경

앱 이름과 파일 이름을 `AIpet.v1`에서 `AIpet`으로 바꿨다(`AIpet.app`, 패키지 `AIpet-<버전>-arm64.zip`). 번들 ID `com.jinoisfree.taesik`, 실행 파일 `Taesik`, 데이터 경로는 그대로다. 위쪽 기록은 당시 이름 그대로 둔다. 동작 변경은 없다.

`scripts/install.py`는 설치와 교체를 함께 한다. 새 사본의 복사와 서명 확인이 끝난 뒤에만 기존 설치본을 종료·교체하고, 그다음에 이전 이름(`AIpet.v1.app`)·다른 응용 프로그램 폴더의 사본·백업(`.bak-…`)을 삭제한다. 번들 ID나 실행 파일이 다르거나 메시지 앱 자동화를 요청하는 번들은 다른 제품으로 보고 건드리지 않으며 버전 비교에도 쓰지 않는다. `Tests/test_install.py` 14건: 신규 설치, 이전 이름·다른 폴더 사본 삭제, 기존 설치본 교체, 백업 삭제, 다른 제품 보존, 대상 위치의 낯선 항목에서 삭제 없이 중단, 복사 실패 시 이전 버전 보존, 종료되지 않는 사본 보존, 검증 실패 시 보존, 교체 실패 시 복구, 낮은 버전 중단과 `--force`, 다른 제품·백업의 버전 무시, 실행 중이던 펫 재실행, 끊긴 훅 경로 안내.

## 1.0.5 손 흔들기 그림과 졸기

손 흔들기는 원본 시트의 넷째 줄 대신 `Resources/Pet/wave.png`(768×208, 네 장면)를 쓴다. `scripts/draw_wave.py`가 원본 시트에서 팔을 짧게, 몸을 날씬하게 다시 그린 결과이며, `scripts/prepare_assets.py`가 픽셀 해시로 고정한다. 스크립트를 다시 돌려 같은 파일이 나오는 것을 확인했다. 원본 WebP와 manifest는 그대로다.

쉬는 상태로 3분 동안 커서·시선·작업이 없으면 존다. 오류 줄의 세 장면을 다시 써서 눈을 감고 고개를 떨구는 동안 z가 하나씩 늘고, 무슨 일이 생기면 깬다. ‘동작 줄이기’에서는 잠든 한 장면으로 멈춘다. 손 흔들기와 졸기는 쉬는 자세와 같은 크기로 그린다. 동작 미리보기에 ‘조는 중’을 더했다.

`Tests/PetAnimationTests.swift`가 3분 기준·깨어남·장면 순서·z의 위치를, `Tests/SpritePresentationTests.swift`가 다시 그린 손 흔들기의 폭과 높이, 졸기의 크기와 바닥 위치를 검사한다. 실제 화면에서 3분을 기다려 조는 것은 확인하지 않았고, 미리보기 장면을 그림으로 저장해 확인했다.

## 1.0.6 생각 말풍선

말풍선과 펫 사이에 지름 15·10.5·6.5pt의 방울 셋을 말풍선과 같은 재질로 그린다. 큰 방울이 말풍선에 붙고 작은 방울이 펫의 머리(말풍선이 아래에 있으면 발) 쪽으로 이어진다. 방울 크기는 말풍선처럼 펫 배율과 무관하며, 작은 배율에서는 방울이 들어가도록 말풍선과 펫의 간격을 넓힌다.

`Tests/PetLayoutTests.swift`가 화면 세 종류·배율 네 가지·가장자리 위치마다 방울이 창 안에 있고 말풍선·서로와 겹치지 않으며 말풍선과 펫 사이에만 놓이는지 검사한다. 빌드한 앱의 화면을 그림으로 저장해 모양을 확인했다.

## 1.0.7 조는 모습

조는 장면을 오류 줄의 그림 대신 `Resources/Pet/doze.png`(768×208, 네 장면)로 바꿨다. `scripts/draw_doze.py`가 쉬는 그림에서 한쪽 눈, 양쪽 눈을 감기고 머리만 3·6픽셀 내려 그린 결과이며, `scripts/prepare_assets.py`가 픽셀 해시로 고정한다. 스크립트를 다시 돌려 같은 파일이 나오는 것을 확인했다.

몸의 크기와 자리는 쉬는 모습과 같고 머리만 움직인다. 눈을 뜬 채로 시작해 한쪽 눈을 감고, 양쪽을 감은 채 세 번 천천히 까딱이며 그때마다 z가 하나씩 늘고, 번쩍 깼다가 되풀이한다(한 바퀴 5.82초). ‘동작 줄이기’에서는 눈을 감고 z 셋이 떠 있는 한 장면으로 멈춘다.

`Tests/PetAnimationTests.swift`가 장면 순서·시간·z 개수를, `Tests/SpritePresentationTests.swift`가 눈을 감아도 윤곽이 쉬는 모습과 같고 까딱일 때 머리만 내려가는지를 검사한다. 빌드한 앱의 미리보기 장면을 그림으로 저장해 확인했다. 실제 화면에서 3분을 기다려 조는 것은 확인하지 않았다.

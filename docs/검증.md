# AIpet.v1 1.0.3 검증

2026-10-01에 공개용 소스를 새 폴더에서 테스트하고 Apple Silicon용 앱과 ZIP을 빌드했습니다. 개인 작업 기록과 설정 대신 합성 이벤트·임시 디렉터리를 사용하는 검증입니다.

## 재현

저장소 루트에서 빌드 의존성을 준비한 다음 순서대로 실행합니다. Python 훅 테스트는 빌드된 앱 실행 파일을 사용하므로 앱 빌드 후 실행해야 합니다.

```bash
bash "$PWD/scripts/test.sh"
bash "$PWD/scripts/build.sh"
python3 -m unittest discover -s "$PWD/Tests" -p 'test_*.py'
bash "$PWD/scripts/package.sh"
```

## 범위와 한계

- 이번 공개 준비에서는 설치된 앱이나 실제 AI 설정을 교체하지 않았습니다. GUI 동작을 새로 조작하는 검증은 수행하지 않았습니다.
- 동시에 실행한 두 AI의 실제 화면 조작 연결, Codex 훅의 사용자 신뢰 승인, macOS 버전별 실행 호환성은 이 테스트 결과만으로 보장하지 않습니다.
- 테스트에서 확인한 작업 우선순위와 창 선택은 합성 기록·창 메타데이터 기반입니다. 실제 도구 출력에 창 정보가 없으면 대상 창을 결정할 수 없습니다.
- 개인정보 검사는 공개 후보 파일과 ZIP에 한정합니다. 로컬 로그·설정·진단 스냅샷·설치 백업은 업로드 대상에서 제외했습니다.
- 릴리스 ZIP은 ad-hoc 서명이며 Developer ID 서명과 Apple 공증을 받지 않았습니다.

## 자산 무결성

`Resources/Pet/spritesheet.webp`의 SHA-256:

```text
316b98b0445cdf0ac50dda91128e5772366f49787a4634addbfb1409c99dca35
```

ZIP의 SHA-256은 릴리스에 첨부된 `SHA256SUMS`를 확인하세요. 다운로드한 ZIP과 같은 폴더에서 검사할 수 있습니다.

```bash
shasum -a 256 -c SHA256SUMS
```

## 1.0.4 이름 변경

앱 이름과 파일 이름을 `AIpet.v1`에서 `AIpet`으로 바꿨다(`AIpet.app`, 패키지 `AIpet-<버전>-arm64.zip`). 번들 ID `com.jinoisfree.taesik`, 실행 파일 `Taesik`, 데이터 경로는 그대로다. 위쪽 기록은 당시 이름 그대로 둔다. 동작 변경은 없다.

`scripts/install.py`는 설치와 교체를 함께 한다. 새 사본의 복사와 서명 확인이 끝난 뒤에만 기존 설치본을 종료·교체하고, 그다음에 이전 이름(`AIpet.v1.app`)·다른 응용 프로그램 폴더의 사본·백업(`.bak-…`)을 삭제한다. 번들 ID나 실행 파일이 다르거나 메시지 앱 자동화를 요청하는 번들은 다른 제품으로 보고 건드리지 않으며 버전 비교에도 쓰지 않는다. `Tests/test_install.py` 14건: 신규 설치, 이전 이름·다른 폴더 사본 삭제, 기존 설치본 교체, 백업 삭제, 다른 제품 보존, 대상 위치의 낯선 항목에서 삭제 없이 중단, 복사 실패 시 이전 버전 보존, 종료되지 않는 사본 보존, 검증 실패 시 보존, 교체 실패 시 복구, 낮은 버전 중단과 `--force`, 다른 제품·백업의 버전 무시, 실행 중이던 펫 재실행, 끊긴 훅 경로 안내.
